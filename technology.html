Technology

An AI-driven design flow, inside the tools the industry trusts

Nexora's AI agents don't replace chip-design tools. They operate them. Agents drive industry-standard schematic, simulation, layout and physical-verification tools through scripts, the same way an engineer would, and every result is checked by those tools' own sign-off checks.

The flow

From specification to verified layout

Each stage ends with a review by the designer before the next begins, so mistakes are caught early and the designer stays in control.

Specification & architecture

The designer defines requirements, chooses the architecture and sets the block-level targets the agents must meet.

Senior designer

Schematic generation

Agents create schematics programmatically and redraw them in clean, textbook-style form, then prove the result is electrically identical to the generated netlist.

AI agents · designer review

Simulation & corner sweeps

Agents build test benches and run process, voltage and temperature corners, Monte Carlo and noise analyses, then flag any spec that fails.

AI agents · designer review

Layout

Placement, power grid and routing are generated by script in stages. Because a full pass takes under a minute, layout can be regenerated whenever the circuit changes.

AI agents · designer review

Physical verification

Design-rule (DRC) and layout-vs-schematic (LVS) checks and parasitic extraction run automatically. Agents fix violations and re-check until the block is clean.

AI agents

Post-layout sign-off & reports

Extracted layouts are re-simulated against the schematic results, and agents write the design report. The designer signs off.

AI agents · designer sign-off

Human in control

The designer decides; the agents do the work

AI agents are fast but not infallible. The flow is deliberately staged so that an experienced designer reviews every step, and results are judged by the same sign-off checks used in any professional flow.

Where an AI-generated layout is not better than a hand-drawn one, we keep the better one. Where it is better, it becomes the reference. In our block-level work, one AI-generated regulator layout came out 17% smaller than the hand layout with about 6 dB better supply rejection, and replaced it.

Parallel agents

Several agents, one design

Multiple AI agents work on different blocks at the same time. They coordinate through shared design notes, a block status board and documented lessons learned. This is how one designer can supervise work that would otherwise need a team.

Every problem an agent solves is written down as a reusable rule, so the flow gets faster and more reliable with each block it designs.
